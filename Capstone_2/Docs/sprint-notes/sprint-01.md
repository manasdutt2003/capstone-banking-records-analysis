#### **Sprint 1: Python Fundamentals & Data Exploration**


### Objective

Learn how to load data, inspect datasets, clean data, filter records, and perform basic aggregations using Pandas.

### Skills Covered

* Reading CSV/Excel files
* Understanding DataFrames
* Data cleaning
* Filtering
* Sorting
* Aggregations
* Handling missing values
* Basic business insights

### Deliverables

**File 1:** Data Cleaning Tasks (Q1-Q20)

* Missing values
* Duplicates
* Invalid records
* Data type conversion
* Standardization

**File 2:** Filtering & Analysis (Q21-Q40)

* Customer filtering
* Transaction filtering
* Balance-based conditions
* Group-based analysis

**File 3:** Aggregations & Reporting (Q41-Q60)

* GroupBy
* Sum
* Count
* Average
* Top customers
* Monthly summaries

### Expected Outcome

By the end of Sprint 1, you should be comfortable performing exploratory data analysis (EDA) and writing clean Pandas queries.
